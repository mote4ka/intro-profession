# Рефлексия по практическому занятию 1

> Черновик для личной редакции перед сдачей: проверьте, что формулировки отражают ваш опыт.

На этой практике я познакомился с тем, как Git хранит историю проекта, а Python получает данные о фильмах через REST API.
Лучше всего мне удалось понять путь данных от введённого названия фильма до отдельных полей ответа.
Самым сложным для меня стало различие между успешным HTTP-ответом и ошибкой, которую сам сервис сообщает внутри JSON.
В основной ветке master хранится базовая рабочая версия, а отдельная ветка позволяет проверять улучшение до его слияния.
Коммит сохраняет осмысленный этап работы, поэтому его важно делать после проверки изменения, пока понятно, зачем оно понадобилось.
Виртуальное окружение .venv изолирует библиотеки проекта и помогает избежать конфликтов с зависимостями других программ.
Файл .env нужен для локального хранения ключа, а исключение этого файла из Git защищает секрет от публикации вместе с кодом.
JSON представляет данные в структурированном виде, и его разбор позволяет извлечь название, год, жанр, режиссёра, актёров и рейтинг.
Визуальные панели среды разработки помогают видеть текущую ветку, изменения файлов и результаты выполнения ячеек ноутбука.
AI-ассистент может предложить обработку ошибок и улучшение читаемости, но каждую такую правку нужно понять и проверить самостоятельно.
Если бы я выполнял задание ещё раз, то раньше добавил бы проверки ошибочного ключа и отсутствующего фильма и внимательнее проверял бы выводы ноутбука перед коммитом.
